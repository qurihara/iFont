# WISS 2026 timeFont（LaTeX 版）

投稿版 v15（`timeFont_WISS2026_投稿版.docx`）を WISS 2026 のテンプレートへ移したもの。
**この時点の内容は投稿版と同一。** 査読対応の修正はこれから入れる。

## ビルド

```
export PATH=/Library/TeX/texbin:$PATH
platex timefont && platex timefont && dvipdfmx timefont
```

`latexmk` も使えるが、同梱の `jwiss.bst` が upBibTeX で警告を出すため、
参考文献は `biblio.tex` の `thebibliography` に直書きしてある（bib は使わない）。

## テンプレート指定の検査（2026-10-18）

`wiss_template.tex` の指定を 1 つずつ現物と突き合わせた。

### 直したもの

| 指定 | 何が違っていたか | 直し方 |
|---|---|---|
| 著者所属のマーク | `\affil` を続けて書くと脚注マークが**重なる**（`\@makefnmark` が幅ゼロの箱） | テンプレートの例のとおり `\affil{…} \affil{…}` と間に半角スペースを入れる |
| 未来ビジョン | 角丸の `screen` 枠・1 段組・見出し中央にしていた | テンプレートの記述をそのまま使う。直角の枠・**2 段組**・見出し左。枠の縦 93mm は変更禁止 |
| 図表キャプション | 図 3 と図 5 のキャプションが本文にも残り**二重**に出ていた（docx で Normal スタイルだったため） | 本文側を削除。`\caption` のみに |
| Overfull | `p < 0.05` の `<` が本文モードで **`¡`** に化けていた（4 箇所） | `$p < 0.05$` と数式モードに。変数 `p` も斜体になる |

### 確認してそのままでよかったもの

- `\documentclass[twoside]{wiss}`／`\journalhead{}` と `\title{}` が同一／`\etitle{}` は空（2012 年に英文タイトル廃止）
- 概要 408 文字（指定は 400 文字程度）。「概要．」と本文が一続き
- ハシラが全奇数ページで同一、ページ幅内
- 本文の文字のはみ出し（Overfull）なし。残る警告 1 件はテンプレート由来の空箱で、見本にも同じものが出る
- 謝辞あり（シングルブラインドのため入れる指定）
- 図は PNG（可逆圧縮の指定）。266〜434 dpi
- 図 1〜5 すべて本文から引用、初出の文と同じページかそれ以降
- 数式は余白内。2 段組、図は 2 段抜きにしていない
- 参考文献は `thebibliography` で手書き（テンプレートは jwiss.bst を推奨だが手書きも可と明記）。英文誌名は斜体、著者はイニシャル＋姓、ページ、発行年
- 用紙 A4、句読点は「，」「．」のみ、である調
- ページ番号は出ないが、テンプレート見本・投稿版とも同じ

### 参考文献と未来ビジョンの重なり（解消済み）

テンプレートが「文章量が増えると，本文と未来ビジョンが重なるため，重ならないように
文章量を調整すること．」と明記している箇所。次の順で直した。

1. 図 1・図 2・図 5 を縮め、本文を 6 ページに収めた（7 ページ目に 4 行はみ出していた）
2. それでも参考文献 15 件が 7 ページ目を使い切って枠に流れ込んだ
3. `\enlargethispage` は 2 段組では使えない（Infinite glue shrinkage でエラー）
4. 参考文献のあとに `\clearpage` を入れ、未来ビジョンを次ページへ送った
5. そのままだと float だけのページになり `[!b]` が効かず上部に出るので、`\mbox{}` を置いた

結果、8 ページ（本文 6・参考文献 1・未来ビジョン 1）。
本文 6 ページ以内の規定は満たす（参考文献・謝辞・未来ビジョンはページ数に含まれない）。

投稿版（Word）は 7 ページで、参考文献と未来ビジョンが同じページに収まっていた。
同じにするには参考文献を 7 ページ目の上半分に収める必要があり、
2 段のバランス調整が要る。査読対応で本文を加筆するとページ配分が変わるため、
その時点で改めて詰める。
