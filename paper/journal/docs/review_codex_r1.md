## 4. 弱みと懸念

### 1. 同等性検定の報告から、中心的な「公平」の結論を追跡できない

**問題。** `main.tex:787` から `main.tex:798` では、紙の形について差が1.8枚、95％信頼区間が \([-0.9,4.5]\)、TOSTの \(p=0.011\) と報告されている。アプリについても、差が－0.8枚、95％信頼区間が \([-3.6,2.0]\)、TOSTの \(p=0.003\) とされている。同じ推定量と標準誤差を用いた通常のTOSTとしては、これらの信頼区間と \(p\) 値を容易に両立させられない。紙の形は特に同等性境界の上側に近い。

**理由。** 「差がない」という帰無仮説を棄却できないことと、差が±4枚以内であることを積極的に示すことは異なる。本稿は後者によって公平性を主張しているため、正確さと総合判定に直接関わる。異なる集約単位や誤差モデルをTOSTに用いた可能性はあるが、その場合も現状の記述では再現できない。

**直し方。** 各条件について、解析単位、モデル式、固定効果、変量効果、自由度、標準誤差、90％信頼区間、二つの片側検定の各 \(p\) 値、TOSTとして採用した大きい方の \(p\) 値、Holm補正前後の値を示すべきである。±4枚を定めた時点と実質的根拠も明記すべきである。再解析で紙の形の同等性が支持されなければ、`main.tex:856` と `main.tex:931` の「差が消え」を「大幅に縮小した」に変更し、タイトルと概要の公平性表現も対応して限定する必要がある。

また、`main.tex:833` のKolmogorov–Smirnov検定は、同一参加者、試合、札から得た多数の押下を独立標本として扱っているように読める。参加者または組を単位とした要約、階層モデル、クラスタ単位の置換検定などに置き換えることが望ましい。公平感評定についても、`main.tex:830` から `main.tex:831` に解析単位とモデルを追記する必要がある。

### 2. 曲線差0.046および0.034が点推定だけであり、「保証」と呼べない

**問題。** `main.tex:703` から `main.tex:705` と `main.tex:720` から `main.tex:724` は、当てはめた曲線間の最大差だけを報告している。観測点、適合度、最大差を求めた時間範囲、時間刻み、推定区間が示されていない。候補版では、同じ測定データを段階選択と残差算出の双方に用いている。

さらに、`main.tex:182` は曲線一致に \(x_0\)、\(\beta_1\)、\(\lambda\) の一致が必要と述べる一方、`main.tex:375` では \(x_0\) と \(\beta_1\) だけを合わせている。表3の理論値も `main.tex:326` で下限と上限を除いて計算されている。

**理由。** 約30試行未満の各セルから推定した曲線には相当の不確実性がある。44札の最大値を使う場合、その不確実性と多重性はさらに大きくなる。点推定上0.034であることから、「全札で0.05以内を保証した」または「理論的に確定する」とは言えない。これは正確さに関わる。

**直し方。** 最大差の定義域、計算方法、\(\gamma\) と \(\lambda\) の扱いを明記し、代表札だけでなく適合度または観測正答率と曲線を提示すべきである。参加者を単位とするブートストラップで、段階選択、パラメータ推定、最大差算出までを含めた区間を求める方法が適切である。区間を示せない場合は、「保証」を「当てはめた曲線の点推定では」に変更すれば、主張を証拠の範囲に収められる。

### 3. 本命試行と確認問題の数が解析試行数と整合しない

**問題。** `main.tex:603` は1名あたり本命60試行と確認問題11試行を行ったと記す。ところが、音声測定の10,579試行は \(149\times71=10,579\) と完全に一致し、フェード測定の52,753試行も \(743\times71=52,753\) と完全に一致する。したがって、`main.tex:624` と `main.tex:662` の「解析した試行」には確認問題が含まれているように見える。本命だけなら、それぞれ8,940試行と44,580試行であり、1セルあたり約25.4試行と約25.3試行になる。

**理由。** 確認問題が曲線当てはめに含まれているなら、打ち切らない条件が過剰に重み付けされる。さらに、確認問題の成績で参加者を除外したうえで同じ確認問題を \(\lambda\) の推定に使うと、上限の推定が上向きに偏る可能性がある。含めていないなら、解析試行数の記述が誤っている。

**直し方。** 各測定について、募集人数、除外人数、解析人数、本命試行数、確認試行数、欠測数、曲線当てはめに投入した試行数を表で示すべきである。確認問題を推定に使った場合は、本命試行だけで再解析するか、確認問題を含める統計的理由を説明する必要がある。`main.tex:715` と `main.tex:720` の「153名（除外2名／3名）」も、153名が除外前か除外後かを明確にすべきである。

### 4. 認識率曲線の一致と対戦の公平性が概念上混同されている

**問題。** `main.tex:181` は集団の強制選択正答率の一致を公平性と定義し、`main.tex:412` から `main.tex:428` は \(1-f(t)\) を「少ない情報で当てた程度」と解釈している。しかし、\(f(t)\) は集団における正答確率であり、個人が得た情報量や識別時刻の百分位そのものではない。

**理由。** 実際の札取りには、知覚後の判断時間、運動開始時間、到達時間、誤答への態度、早期推測の戦略が含まれる。したがって、曲線一致から取り札数の一致が数学的に保証されるわけではない。対戦実験はこの橋渡しを経験的に評価している点で価値があるが、`main.tex:857` の「そのまま反映された」や `main.tex:428` の「厳密に補正される」は強すぎる。

**直し方。** 「知覚段階の公平性」と「対戦結果の公平性」を区別し、前者を設計上の代理指標、後者を実験で評価する結果指標と位置づけるべきである。早押し度は「集団正答率に基づく校正得点」と説明し、その成立仮定を記すとよい。

### 5. ミリ秒単位の設計を再現するための表示条件と判定手順が不足している

**問題。** `main.tex:656` から `main.tex:668` では \(D=25\) ms、\(x_0=9\) ms、\(\beta_1=0.55/\mathrm{ms}\) を報告している。この傾きの10％から90％までの幅は約8 msであり、60 Hz表示の1フレームである約16.7 msより短い。しかし、クラウド参加者のリフレッシュレート、描画方式、8個の打ち切り時点、フレーム落ちの検出、フォント、文字寸法、背景、観察距離が示されていない。

`main.tex:550` ではVOICEVOXの話者名、モデル、バージョン、調整値が示されていない。`main.tex:583` の遅延校正はアプリ機器について記されているが、紙の形で用いた27型画面の描画遅延が測定されたかは不明である。

また、`main.tex:701` では文字が音声より最大64 ms先に始まる。見る役について文字開始を第一音とみなす `main.tex:392` から `main.tex:394` の規則を、人間の審判がどのようにミリ秒単位で適用したかが記されていない。

**理由。** 本稿の貢献は数十ミリ秒の提示差に依存するため、一般的なシステム論文より詳細なタイミング記述が必要になる。これは医学的な厳格さではなく、システムの再現性に必要な情報である。

**直し方。** 刺激の全設定、各打ち切り時点、描画API、フレーム時刻の記録法、対象ブラウザと端末条件、実験機器の型番とリフレッシュレート、紙の形を含む遅延校正、話者と合成パラメータを記載すべきである。早取りについては、ログ、補助表示、録画、審判用信号など、実際の判定方法を説明する必要がある。

### 6. 直接関連する先行研究、とくに著者ら自身の研究が抜けている

**問題。** `main.tex:117` から `main.tex:155` は一般的なゲームアクセシビリティとプレイヤーバランシングを扱う一方、感覚の異なる人が共に競うかるた、リアルタイム多感覚ゲーム、著者ら自身のインクルーシブかるた研究を引用していない。

**理由。** 現在の「著者らの知る限り」という新規性主張を評価するには、かるた固有の既存システムとの差が不可欠である。とくに2025年のEC研究会およびWISS報告は著者が重なり、読者が研究系列と差分を理解するために必要である。

**直し方。** 第7節に挙げる文献を追加し、従来研究が何を公平化し、本稿が時間ごとの認識率校正として何を新たにしたかを比較表または文章で説明すべきである。既発表部分との重複と本稿で新たに加わった部分も明記する必要がある。

### 7. 一般化とアクセシビリティに関する一部の記述が証拠を越えている

**問題。** `main.tex:908` から `main.tex:914` の限界記述は適切である一方、`main.tex:933` は字幕や読み上げ提示への「広い適用」を結論として述べる。`main.tex:63` の「現在の字幕」に関する二分法も、逐次的なリアルタイム字幕を含んでいない。

**理由。** 評価した対象は、聴者が音を切って見る役を担当した、上毛かるた、合成音声1話者、特定書体のフェードである。ろう者や難聴者への有効性、一般の字幕理解、連続文章の読解は未評価である。

**直し方。** 一般字幕への適用は「将来検討できる可能性」に留めるべきである。「聴覚障害」というキーワードは問題設定として残せるが、有効性が確認済みであるような表現は避ける必要がある。ろう者を追加した実験は本稿の採録条件としなくてよい。

## 6. 事実誤認・矛盾・数値の不整合

1. `main.tex:96` は「候補版と精密版の提示とアプリでは差が消えることを示した」と述べるが、`main.tex:764` から `main.tex:768` の対戦条件は補正なし、精密版、アプリだけである。候補版は対戦評価されていない。

## 9. 著者に勧める修正の一覧

### 採否に関わる修正

1. 最優先で、TOSTを再現可能な形で報告し、90％信頼区間と各片側検定を示す必要がある。再解析結果に応じて、「公平」「差が消えた」という表現を限定すべきである。

2. 曲線差の定義、計算範囲、\(\lambda\) の扱い、適合度、不確実性を示し、「保証」「厳密」「収束」という語を証拠の範囲に調整する必要がある。

3. 本命試行と確認問題を分けて人数・試行数を訂正し、確認問題を曲線推定に使った場合は、その影響を再解析する必要がある。

4. 表示フレーム、打ち切り時点、合成音声、機器、遅延校正、紙の形での早取り判定手順を追記する必要がある。

5. EC 2025、WISS 2025、Auditory Uta-Karutaなどの近接研究を引用し、本稿の新規部分を明確にする必要がある。

6. 候補版を対戦評価したという `main.tex:96` の記述、104 msと約200 msの食い違い、第一音の原点に関する記述を訂正する必要がある。

7. 参加者から同意を得た旨を追記する必要がある。

### 改善の助言

1. 可能であれば、札ごとの観測正答率、当てはめ曲線、パラメータ、残差、匿名化した対戦結果を付録またはリポジトリで公開すると、再利用価値が高まる。

2. 既存データで、条件順序、条件内の第1試合と第2試合、経験者と未経験者を含めた感度分析を示すと、学習効果に関する限界をより具体的に説明できる。

3. 公平感評定は平均だけでなく分布を示し、4との差を検定する場合は参加者と組の反復を考慮するとよい。

4. `main.tex:933` の一般字幕への適用は将来展望に移し、本稿の実証範囲を「聴者が聞く役と見る役を交代した上毛かるた対戦」に限定するとよい。

5. ろう者または難聴者による追加実験、参加者数の増加、事前登録、検出力分析は、本稿の採録条件とする必要はない。

## 10. 査読者としての自信の度合い

自信の度合いは5段階で4である。HCI、エンタテインメントコンピューティング、アクセシビリティシステム、心理測定曲線、混合モデル、同等性検定を用いたシステム評価については十分な専門性がある。

判断に迷った点は三つある。第一に、生データと解析コードがないため、TOSTの \(p\) 値が別の集約方法から得られた可能性を排除できない。第二に、表示フレームと打ち切り実装を確認できず、9 ms前後の推定値が実際にどのように提示されたかを判断できない。第三に、上毛かるたの文言利用に関する法的判断は専門外であり、適法性の結論は示していない。これらを除けば、中核的な着想と実験結果には採録に値する可能性が高いと判断する。
