## 2. 総評と採否の見立て

判定は**条件付採録**が妥当であり、総合評価は**3/5**と判断する。採録寄りではあるが、主結果である同等性の統計モデルと認識率差の不確実性について、既存データによる再確認を要するという意味でボーダーである。追加の聴覚障害者実験や参加者の大幅な増員は採録条件としない。

**新規性は4/5である。** 音声と文字の認識率曲線を時刻ごとに対応させ、提示側の候補選択、測定と更新による精密化、判定側の早押し度という三つの構成へ展開した点には明確な独自性がある（main.tex:85-98）。一方、異なる感覚条件を持つ競技者間のゲームバランスを扱う直接的な先行研究が関連研究から漏れており、「例はない」という主張（main.tex:165）は比較対象を追加して限定する必要がある。

**有用性は4/5である。** 延べ1,210名を募集したクラウド測定と、役を交代する10組の対戦を組み合わせ、紙の形とアプリの双方を実装した点は実用的である。遅延を実測して補正している点も実装論文として価値が高い（main.tex:585-603）。現時点の有効範囲は、上毛かるた、合成音声1話者、特定書体、聴者による対戦に限られる。

**正確さは3/5である。** 事前に同等性幅を定めたTOST、条件順の釣り合わせ、参加者単位のブートストラップは適切な方向である（main.tex:797-818）。しかし、役を交代した2試合の依存構造を組のランダム切片だけで扱えるかが明らかでなく、モデル式も示されていない。また、認識率差の点推定が0.05以内である一方、ブートストラップ区間の上端は0.05を超えている。この二点は中心的主張の精度に関わる。

**本学会との関連は5/5である。** 動的文字提示、アクセシビリティ、ゲームバランシング、実時間インタラクション、認識率推定を統合しており、HCIおよびエンタテインメントコンピューティングとの関連は非常に強い。

## 3. 強み

1. 知覚指標と競技結果を混同していない。原稿は「曲線の一致から取り札数の一致が導かれるわけではない」と明記し、後者を対戦実験で別に評価している（main.tex:198-200）。この区別は論文全体の論理を強くしている。

2. 一つの着想を利用条件の異なる三つの仕組みに展開している。原稿は公平化の仕組みを「3つ構成した」とし、紙で利用できる候補版・精密版と、自動判定するアプリを明確に分けている（main.tex:85-91）。

3. 測定規模が主張の型に見合っている。通し読み149名、五段階フェード743名、精密版151名および150名を解析しており（main.tex:645、686、740、745）、アーティファクトの校正に十分な量の測定を段階的に行っている。

4. 不確実性を無視せず、「参加者を単位とするブートストラップ」を実施している（main.tex:729）。現状では解釈の修正が必要であるものの、参加者内相関を意識した解析方針は適切である。

5. 対戦実験では「条件ごとに2試合（役を交代）」し、条件順をラテン方格で釣り合わせている（main.tex:797-798）。さらに同等性幅を「実験の前に定めた」と記載している（main.tex:813-815）。10組という人数そのものは、本分野のシステム評価として不適切ではない。

6. 実装遅延を実測し、「差し引いたあとの残差は±3 ms」と報告している（main.tex:585-603）。数十ミリ秒の差を扱うシステムにおいて、この校正は重要である。

7. 対象者の範囲を比較的慎重に記述している。原稿は「ろう者や難聴者の文字の読み取りが聴者と同じ曲線に従うかは確認していない」と明記している（main.tex:938-943）。聴覚障害者に対する直接的な有効性を実証済みとはしていない点は適切である。

## 4. 弱みと懸念

### 1. 対戦結果の同等性を支える解析単位とモデルが十分に示されていない

**問題：** 各組が同じ条件で役を交代した2試合を行う一方、解析は「試合を単位」とし、「組を変量効果」とすることだけが記載されている（main.tex:797-818）。個人の技量差は役の交代によって結果への符号が反転するため、組のランダム切片だけで依存構造を表せるかは、現在の記述から判断できない。モデル式、固定効果、自由度、推定法、役順および試合順の扱いも示されていない。

**理由：** 紙の形とアプリが±4枚の範囲で同等であるというC5、C6が、本論文の中心的な正確さに関わるためである。この懸念は10組という人数ではなく、独立な単位と反復測定の扱いに関するものである。

**直し方：** 二つの役交代試合を組内で平均し、10組を独立単位とした解析を感度分析として示すか、個人、役、順序を含む混合モデルを完全に記述すべきである。推定差、90%信頼区間、TOSTの生のp値と補正後p値を報告し、Holm補正の比較族を明記すべきである。補正後p値を示す場合には、通常の90%信頼区間との「等価」という記述（main.tex:814）も整理する必要がある。また、「補正により差が消えた」と因果的に述べるなら、補正なしと各補正条件との差について計画比較を示すべきである。

### 2. 0.05以内という全札の主張が点推定と不確実性を混同している

**問題：** 候補版の点推定は最大0.046であるが、ブートストラップ区間の上端は最大0.071である（main.tex:727-730）。精密版も点推定は0.034であるが、上端は0.056である（main.tex:745-747）。それにもかかわらず、概要と結論は不確実性を付さず「全札で0.046以内」「0.034以内」と述べている（main.tex:33、886、961）。

**理由：** 「観測された点推定が閾値内だった」という主張と、「母集団において全札が閾値内だと確認した」という主張は異なるためである。また、記載された区間が各札の区間の上端を比較したものか、各再標本化で44札の最大値を求めた同時的な区間かが判別できない。

**直し方：** 停止基準が点推定に対する運用上の基準であることを明記すべきである。さらに、各ブートストラップ標本で44札の最大値を算出した分布を用いて、全札についての同時的な上限を報告すべきである。その上限が0.05を超える場合は、「実測点推定では全札が0.05以内であった」と主張を限定すればよく、新たな参加者の募集を必須とはしない。

### 3. ロジスティック曲線の適合性と階層化の記述が不足している

**問題：** 各札を8時点、各時点約25試行で測定し、上限を自由推定する三パラメータ相当の曲線を当てはめている（main.tex:623、628-632）。一方、再掲された生の正答率には、「つ」の71%から41%、「し」の42%から12%など大きな非単調変動がある（main.tex:258-276）。適合度、不適合札、境界推定、残差は報告されていない。また、経験ベイズで縮約すると説明されるのは \(\log\beta_1\) だけであるのに、次行では \(x_0\) も縮約値だとされている（main.tex:631-632）。

**理由：** 曲線の差、候補選択、精密版の更新、アプリ得点がすべて曲線推定に依存するためである。原稿自身が適合度評価の文献を引用している（main.tex:156）ことからも、診断結果を示す必要がある。

**直し方：** 各時点の観測値と区間、適合度指標、境界に達した推定数、札ごとの残差分布を本文または付録に示すべきである。参加者単位の再標本化を曲線推定にも一貫して適用し、固定した下限と自由な上限に対する感度分析を加えることが望ましい。\(x_0\)を縮約したのであれば階層モデルを記述し、縮約していないのであればmain.tex:632を訂正すべきである。

### 4. 精密版の更新規則は再実装できず、「収束」という表現も強い

**問題：** 対応づけ \(g\) はmain.tex:414で突然現れ、定義されていない。実際の更新も、「残差の向きに応じて \(D\) を0.6から1.5倍、\(\Delta\) を±18 msの範囲で修正」としか記載されていない（main.tex:735-737）。二回の測定で停止基準に到達したことは示されるが、反復列の安定性や収束性は示されていない（main.tex:420-424）。

**理由：** 精密版は主要な方法論的貢献であり、更新則を再実装できることが正確さと有用性の双方に必要である。

**直し方：** 残差から \(D\) と \(\Delta\) を決める式、目的関数、上限処理、擬似コードを示すべきである。「収束」は数学的な収束ではなく、「二回目の測定で点推定による停止基準に到達した」と記述すべきである。

### 5. 刺激と実験手続きの再現に必要な情報が不足している

**問題：** 視覚刺激の8打切り時点が記載されておらず（main.tex:673-683）、書体、文字寸法、前景色、背景色、停止後の表示方法も明らかでない。VOICEVOXについても話者名、スタイル、バージョン、合成パラメータがない（main.tex:562-570）。クラウドソーシングのサービス、参加者属性、聴覚・視覚条件、ブラウザや画面条件も十分に示されていない（main.tex:619-626）。対戦実験では札の読上げ順、配置のランダム化、最初の役の割当てが不明である（main.tex:797-804）。

**理由：** 一話者、一書体、一環境に限定された結果であるからこそ、その環境を特定しなければ再現可能性と適用範囲を判断できないためである。投稿中で未公開のWISS原稿への依存では、この不足を補えない。

**直し方：** 刺激仕様、音声ファイルまたは再生成設定、名目打切り時刻、実測時刻の扱い、募集元、属性、機器条件、無作為化と役順を表または付録にまとめるべきである。

### 6. 一部の公平性表現が証拠の範囲より広い

**問題：** 概要と結論は「取り札数の差が消え」「advantage vanishes」と述べる（main.tex:34、45、962）。実際の推定差は紙で+1.2枚、アプリで−0.8枚であり、証拠が示すのは事前規定した±4枚以内の同等性である（main.tex:823-827）。また、アプリが「厳密に補正でき」るという表現（main.tex:903）は、個人差と運動時間を補正しないという記述（main.tex:446）と整合しない。

**理由：** 聴者20名、特定音声、特定書体、特定機器についての結果を、一般的な聴者、ろう者、難聴者、または任意の環境へ拡張してはならないためである。

**直し方：** 「聴者10組の本実験では、差が事前規定した±4枚の同等性範囲内に収まった」と記述すべきである。「厳密に補正」は「集団レベルの認識率曲線に基づいて判定を補正」に変更すべきである。ろう者・難聴者による追加実験は将来課題のままでよく、採録条件とはしない。

### 7. 直接的な関連研究、投稿中文献、権利記述を整理する必要がある

**問題：** 感覚能力が異なる参加者間の競技バランスを直接扱う研究が関連研究から漏れている（main.tex:118-139、165）。また、参考文献[2]は「WISS 2026 投稿中」である（main.tex:975-976）。権利についても、「短い句の文言そのものに権利はないと判断した」と法的結論を断定している（main.tex:605-612）。

**理由：** 関連研究の不足は新規性評価に影響する。情報処理学会は投稿中で未刊行の文献を参考文献に記載できないとしている。群馬県公式ページは上毛かるたの著作権・商標権が県へ譲渡されたと説明しているが、そこから個々の短句の法的扱いまでは確認できない。

**直し方：** 第7節の確認済み文献を比較対象として追加し、独自性を「認識率曲線による早押し競技の時系列校正」に限定すべきである。WISS原稿は別紙で編集委員会へ開示し、刊行または採録されるまで参考文献から外す必要がある。権利記述は、県または専門部署への確認結果を示すか、著者による法的断定を避けて利用範囲と相談状況を記述すべきである。

## 6. 事実誤認・矛盾・数値の不整合

1. main.tex:188の「認識率が10%から90%まで上昇するのに要する時間の幅は \(4.39/\beta_1\)」は、\(\gamma=0,\lambda=1\)の場合に限って成り立つ。一般の式では、「下限から上限までの振幅を正規化した10%点から90%点」と書く必要がある。

2. main.tex:631では \(\log\beta_1\) だけを縮約すると説明しているが、main.tex:632では \(x_0\) と \(\beta_1\) の双方を縮約値としている。\(x_0\)の階層モデルが欠落しているか、main.tex:632の記述が誤っている。

3. main.tex:235では基礎測定を68択としているが、main.tex:311では同じ測定を「67音」としている。選択肢数と解析対象音数が異なり得るため直ちに誤りとは断定しないが、除外された音または選択肢の内訳を説明する必要がある。

4. main.tex:33、886、961の「全札で0.046以内」「0.034以内」は点推定については一致しているが、main.tex:729、746のブートストラップ上端0.071、0.056を反映していない。これは算術的不一致ではなく、推定値と不確実性の表現上の不整合である。

5. main.tex:34、45、962の「差が消えた」という記述は、本文の+1.2枚および−0.8枚という値と文字どおりには一致しない。正確な記述は、「事前規定した±4枚の範囲で同等性が支持された」である。

## 9. 著者に勧める修正の一覧

### 採否に関わる修正

1. 役交代を含む対戦データを、組平均または依存構造を明示した混合モデルで再解析し、モデル式、90%信頼区間、TOST、Holm補正の比較族を報告すべきである。

2. 候補版と精密版について、44札の最大残差を各再標本化で計算する同時的なブートストラップ結果を示すべきである。現データで0.05以内を保証できない場合は、点推定に限定して主張を書き換えるべきである。

3. 曲線の適合度、境界推定、経験ベイズの対象パラメータを明示し、main.tex:188およびmain.tex:631-632の数理的・記述上の不整合を訂正すべきである。

4. 精密版の更新式または擬似コードを追加し、「収束」を「停止基準への到達」に改めるべきである。視覚刺激、音声合成、打切り時点、募集条件、実験順序について再現可能な情報も補う必要がある。

5. 対戦結果の結論を「聴者10組の本実験では事前規定した±4枚の範囲で同等性が支持された」に限定し、「差が消えた」「厳密に補正できる」という表現を改めるべきである。

6. 第7節の直接的な関連研究を追加し、新規性を認識率曲線による時系列校正に限定して説明すべきである。

7. 投稿中のWISS文献を参考文献から外して別紙で開示し、先行原稿に依存する方法を本稿内で自足的に説明すべきである。併せて、六つの図ファイル名を修正すべきである。

これらは原則として既存データの再解析、方法の追記、主張の限定によって対応できる。事前登録、検出力分析、数百名規模の追加対戦、無作為化比較試験、ろう者・難聴者による追加実験は採録条件としない。ただし、再解析後に±4枚の同等性が支持されない場合には、中心的結論を変更する必要がある。

### 改善のための助言

1. 公平感評定について平均だけでなく信頼区間を示し、中立点4との関係を記述することが望ましい。

2. 一文字から五段階を選ぶ一般化について、相関係数だけでなく、選択段階の一致率または選択後の残差を示すことが望ましい。

3. 音声、刺激生成設定、曲線データ、解析コード、アプリを権利上可能な範囲で公開すると、アーティファクトとしての有用性が高まる。

4. ろう者・難聴者による評価は、現論文の欠落を埋める必須実験ではなく、本来の利用対象へ妥当性を拡張する次段階として実施することが望ましい。

5. 上毛かるたの文言利用については、法的断定を避け、県または所属機関の専門部署に確認した範囲を記載することが望ましい。

## 10. 査読者としての自信の度合い

本判定に対する自信は**4/5程度**である。HCI、エンタテインメントコンピューティング、アクセシビリティ設計、反復測定実験、心理測定関数、混合モデルおよび同等性検定について査読可能な専門性を有する。

判断に迷った最大の点は、生データがないため、役交代を組平均で扱った場合にもTOSTの結論が維持されるかを確認できないことである。また、WISS投稿中原稿との重複範囲、使用した音声と刺激の完全な仕様、上毛かるたの短句に関する法的判断も確認できなかった。これらの不確実性があるため無条件採録とはしないが、提案の独自性と実証の厚みは認められ、既存データによる確認と主張の限定が済めば採録に値すると判断する。
