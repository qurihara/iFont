# timeFont 論文誌原稿（未来日記方式）

情報処理学会論文誌に投稿する原稿「認識率の曲線に合わせて文字が現れる動的フォント timeFont による聞く人と見る人の公平なかるた対戦：上毛かるたへの適用と評価」を，未来日記方式（理想的な結果が得られたと仮定して先に書き，実測で後追いする方式）で書いたものである．著者は栗原一貴（筆頭）と丸山礼華．作成日 2026-10-08．

## 重要な注意

**この原稿の 6 章・7 章・8 章の数値は，まだ実測していない想定の値である．** 本文では `\begin{fd}...\end{fd}`（段落）と `\fdcaption`（図表）の印で区別してあり，下書き版の PDF では青い文字と赤い札「［未来日記 id・planned］」で表示される．図は `_synthetic` を末尾に持つファイルで，図の中に「仮想データ」と描き込んである．

投稿版（`./build.sh final`）は，印が 1 つでも `done` 以外のまま残っているか，`_synthetic` の図が本文に埋め込まれていれば，組み立てを止める．この関門は外さない．

## 組み方

TeX 処理系は，この機械では利用者領域に導入した TinyTeX（`/Users/kurihara/Library/TinyTeX/bin/universal-darwin`）の platex と dvipdfmx を用いる．`build.sh` が PATH に加える．

```
cd /Users/kurihara/Desktop/claude-work/iFont-paper/paper/journal
./build.sh draft    # 下書き版 timefont_journal_draft.pdf
./build.sh final    # 投稿版（未解決の印が残っていれば止まる）
python3.11 make_figs.py   # 図を作り直す
```

TinyTeX を別の機械に入れるには，`curl -sL https://yihui.org/tinytex/install-bin-unix.sh | sh` のあと `tlmgr install collection-langjapanese latexmk` を行う．

## 実測に置き換える手順

1. `future_diary_status.md` の未解決の印から 1 つ選び，`desc` に書かれた作業を行う．
2. 本文の数値を実測値に書き換える．先に置いた値に合わせて実験してはならない．
3. 図は `make_figs.py` の入力を実測値に差し替え，「仮想データ」の描き込みを消し，ファイル名から `_synthetic` を外し，`_synthetic` のファイルをその場で消す．
4. 印の `status` を `done` にする．
5. `./build.sh draft` で確かめ，全部が `done` になったら `./build.sh final` を通す．

## 推敲

paper-style スキルの `style_check.py --all-positions`，`hihouwa_check.py`，`katakana_check.py`，`kunyomi_check.py` を掛けて裁定した（2026-10-08）．裁定の要点は次のとおりである．

- 否定から書き始める段落（癖1）: 2 件を肯定形に直した（概要の第 1 文，一対比較の結果の文）．
- 経緯の語・比喩（癖2・4）: 「基礎として用い」「測定の面では」「ことが分かった」など 5 件を直した．「その結果」（章の内容の指示）は残した．
- 非飽和名詞の書き出し（癖10）: 10 件すべてに「何の」を補った（「取りの判定」「候補版を作成する手順」「対戦の条件」など）．検査では 0 件になった．
- 訓読みの動詞（癖7）: 149 件から 93 件に減らした．直したのは，測る・確かめる・選ぶ・合わせる（$x_0$ の操作）・決まる・収まる・要る・作る・使う・広げる・埋める・動く・上げる・近づく・済む・崩れる・効く・劣る・知る など．残したのは，聞く人・見る人・読む・押す・触れる・現れる・分かる・当てる（かるたの体験の描写と，主張の平易さを担う語），打ち切る・読み上げる・作り直す・測り直す（複合動詞），仮定を置く・事前分布を置く・割合を占める（学術の慣用），「速さに合わせて設計する」（timeFont の定義の文言）である．
- 否定で終わる文（癖6）: 427 文中 18 文（4.2%）．残したのは限界と設計の明言である．
- 全称: 「すべての札が第一音で確定する」「44 枚すべての先頭字が異なる」は上毛かるたの事実，「任意のスケジュール」は方向 2 の主張の引用なので残した．
- カタカナ語: 1 万字あたり 132 件で，避けすぎの語は見当たらなかった．

### 二周目（2026-10-08）

同じ 4 つの検査をもう一度掛け，候補を 1 件ずつ裁定した．候補の既定は「残す」とし，直すことで読者が得るものを言える箇所だけを直した．直したのは約 45 か所で，候補全体の 1 割強である．内容（主張・構成・数値）は変えていない．

| 検査 | 前 | 後 |
|---|---|---|
| `style_check.py --all-positions` の訓読みの動詞の候補 | 383 件（文末の終止形を含む語 37） | 360 件（同 33） |
| `kunyomi_check.py`（92 語の照合） | 94 件（1 万字あたり 47.0） | 87 件（同 43.3） |

| `katakana_check.py` | 262 件（1 万字あたり 131） | 266 件（同 132） |

裁定の方針は次のとおりである．

- 比喩と擬人化（癖4）: 研究の道具を主語にした人の行為（「この仕組みは…と仮定する」「この方法は…仮定を置く」）を「…という仮定にもとづいている」の形に直した．「本稿は…」は「本稿では…」に統一した（3 件）．「当て推量の床」は「下限」（上限と対にする），「44 音の本体」は「10〜90 パーセンタイルの範囲」，「正答率の軸」「情報量の軸」は「正答率を一致させる提示」「情報量の軌跡による転写」，「状態の階段として組む」は「静止状態の段階的な切り替えとして構成する」，「跳ね上がる」は「急に上昇する」，「識別を助ける」は「識別の手がかりになる」，「規則の解釈に手を加える」は「変更する」，「見せ方を歪め」は「提示の時間軸を変形し」に直した．「時間の形」は他の箇所の「時間構造」に揃えた．残したのは，他者の研究を主語にした紹介文（「これらの研究は…扱っていない」），人でないものにも成り立つ関係や状態の文（「結果は…を示す」「候補版は…から成る」），分野の術語（「曲線が立ち上がる」「階段状」「縮約」），物理の動作（「手を伸ばす」「手を出す」「画面を正面に置く」）である．
- 訓読みの動詞（癖7）: 「見せる刺激」「見せ方」「見せるアニメーション」の 7 件を，原稿の他の箇所で用いている「提示」に統一した（1 つの概念に 1 つの語）．届かず→達せず，情報が届く→到達する（「到達の時間構造」に揃える），人が分かり・時計も 1 つで済み→プレイヤーを識別でき・時計を 1 つで共用でき，知る→把握する，答えた→回答した（6.1 節の「回答させた」に揃える），整っている→整備されている，描く→描画する，触った→触れた（他の箇所に揃える），縮まった→縮小した，引ける→特定できる，曲線が立たなかった→立ち上がらなかった（他の箇所に揃える），使える→利用できる（8.3 節に揃える）とした．残したのは，聞く・見る・読む・押す・触れる・現れる・分かる・当てる・競う・勝つ（かるたの体験の描写と主張の平易さを担う語），打ち切る・読み上げる・作り直す・絞り込む・差し引く（複合動詞），事前分布を置く・割合を占める・当てはめる・釣り合わせる（統計の慣用），手を伸ばす・並べる・ヘッドフォンを外す（物理の動作），一字決まり・空読み・本読み（術語），「声が少しずつ届き」（要旨と序論の冒頭の体験の描写），反復を止める・成り立つ・限る・丸める（操作を特定しており，熟語に替えても読者が得るものがない）である．
- 否定で終わる文（癖6）: 否定が 3 つ重なる 1 文（「依存が認められず，依存もなく，制約もない」）を「いずれからも独立であり，…とも無関係である」に組み直した．残り 16 文は，限界の記述（6 文），関連研究との対比（2 文），実装と手続きの明言（「音声は提示しない」「見直しは設けない」），事実の記述（「濁音で始まる札はない」），新規性の主張（「例はない」）であり，肯定形にすると限界の記述が弱まるか主張が変わるので残した．
- 演出の一文（癖9）: 「刺激も新しく設計せずに作成できる．文字のアニメーションの速さを変えるだけで速さの段階ができる．」は同じ内容の 2 文なので，「刺激も，文字のアニメーションの速さを変えるだけで用意できる．」の 1 文にした．段落末の短文の他の 27 件は，並列の列挙の最後の項か，接続語・指示語を伴う結論の文であり，残した．
- 非飽和名詞の書き出し（癖10）: 検査では 0 件だったが，見出しの直後で受ける相手のない「主な指標は」「画面の大きさは」に，「対戦実験の」「アプリの」を補った．
- 全称表現・主語のない文・文体の検査: 一周目と同じ理由で残した（上毛かるたの事実，方向 2 の主張の引用，著者が動作主の報告文，数学の「関数」，章の内容を指す「その結果」）．

組み直した結果，印なし版は 15 ページのままで，Overfull の数も 6 のまま（表の列幅によるもので，推敲の前から同じ）である．下書き版は青い段落と赤い札の分だけ長く，著者紹介の末尾 3 行が 16 ページ目に送られた．投稿に用いるのは印なし版なので，字数を稼ぐための語の切り詰めは行っていない．
