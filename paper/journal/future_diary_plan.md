## 印の規約（LaTeX）

- 段落: `\begin{fd}{id}{status}{owner}{desc} ... \end{fd}`
- 図表のキャプション: `\fdcaption{id}{status}{owner}{desc}{キャプション}`
- id の接頭辞: E 事例・手続き、N 数値、F 図、T 表。章番号を続ける。
- status: planned / doing / done。owner: kurihara / maruyama / claude。
- desc: 何をすればこの記述が事実になるかを一文で書く。
- 下書き版（`./build.sh draft`）は印の段落を青で組み、先頭に赤い札を付ける。投稿版（`./build.sh final`）は done でない印が1つでも残れば止まる。`_synthetic` の図が含まれていても止まる。
