# かな「ほ」と「こ」の混同は、聴覚の較正データに現れているか

作成日: 2026-10-08。作成: Claude(Fable 5.1)。依頼: 栗原一貴さん。

## 1. 目的

上毛かるたの競技県大会規則の「読み手に関する注意事項」には、
「紛らわしく聞き取りにくい読み札(ほ、こ等の札)については特に注意すること」と書かれている。
競技の現場で知られているこの混同が、我々の測定データ(かな1音を途中まで聞かせて68音から当てる課題)でも
現れているなら、timeFont を上毛かるたに応用することの妥当性の傍証になる。
この資料は、聴覚の較正実験のデータから「ほ」と「こ」の混同の大きさを数え、
ほかの音の混同と比べて、どの程度の位置にあるかを示したものである。

## 3. 方法

1. 区分ごとに、目標の音 × 回答の音の混同行列(件数)を作る。
   上毛かるたの先頭音 44 音の範囲では、44 音以外の回答(濁音・半濁音・ん)を「他」の列にまとめた。
2. 「ほ」が目標のとき「こ」と答えた割合(ほ→こ)と、「こ」が目標のとき「ほ」と答えた割合(こ→ほ)を、
   区分ごとに出す。割合の分母はその目標の音の試行数である。不確かさは Wilson の 95% 信頼区間で示す。
3. 比較のために、目標の音ごとに「最も多い誤答先」とその割合(その目標の試行数で割ったもの)を一覧にし、
   ほ→こ・こ→ほ の割合が、その一覧の中でどの位置にあるかを数える。
   また、目標 ≠ 回答のすべての組(観測されたもの)を割合の順に並べ、ほ→こ の組が何位かも数える。
4. 混同が対称かどうかは、ほ→こ と こ→ほ の 2 × 2 表に Fisher の正確検定を当てて見る。
5. 図は 44 音の混同行列(行=目標、列=回答)で、色は目標ごとの割合の平方根の階調である。
   ほ・こ の交差する 2 つのます(ほ→こ、こ→ほ)を赤い枠で囲み、対角のますを赤い破線で囲んだ。

### 4.5 感度分析

でたらめ回答の疑いで除いた 2 名を含めた場合(90 名、5,400 試行)でも、ほ・こ に関わる件数は
すべて同じで(ほ→こ 5/66、こ→ほ 0/57)、結論は変わらない。出力は `sensitivity_keep_all/` にある。

## 5. 解釈

1. **ほ→こ の混同は存在するが、大きくはない。** 全体で 7.6%(5/66)、短い打ち切りで 10.7%(3/28)であり、
   「ほ」の誤答先としては は(35%)、ぱ(11%)に次ぐ 3 番目である。他の音の最多誤答(中央値 19〜23%)と比べると、
   目標 ≠ 回答の全 808 組の中で 130 位、44 音の範囲の 403 組の中で 65 位にとどまる。
2. **混同は片方向である。** こ→ほ はどの区分でも 0 件で、「こ」は 84% の正答率を持つ聞き取りやすい音である。
   「ほ」は 21% しか当たらず、短い打ち切り(10〜40 ms)では 28 試行中 1 試行しか当たらない。
   つまり、規則が言う「聞き取りにくい」は「ほ」には当てはまるが、「こ」には当てはまらない。
3. **「ほ」の聞き取りにくさは、母音の取り違えとして現れる。** 「ほ」の誤答は は・ぱ・ふ・ひ のように
   子音 /h/ の行の中で起き(66 試行中 33 試行)、子音を取り違えた こ・お・と はそれより少ない。
   /h/ は息の音で立ち上がりが弱く、母音 /o/ が聞こえる前に打ち切られると、同じ行の「は」と区別がつかない、
   という説明と整合する。また「ほ」という回答自体が 5,280 試行中 17 件しかなく、参加者が「ほ」を選びにくい
   傾向も疑われる。
4. **競技の現場の知見との関係。** 競技規則の「ほ、こ等の札」は、札の読みの全体(「ほ」の札は「誇る文豪 田山花袋」、
   「こ」の札は「心の灯台 内村鑑三」)を速く読み上げたときの紛らわしさを指していると考えられる。
   この 2 つの読みは 2 拍目がどちらも「こ」であり、1 拍目の「ほ」が弱く聞こえると、2 拍目の「こ」から
   「こ」の札だと取り違える、という経路が考えられる。我々のデータは 1 音だけを聞かせたものなので、
   この経路は測れていない。1 音の段階で言えるのは、「ほ」が実際に聞き取りにくい音であること、
   そして「ほ」を「こ」と聞く誤りが 1 音の段階でも一定数(1 割弱)観測されること、の 2 点である。
   したがって、競技の現場の知見は「ほ」については我々のデータと整合し、ほ→こ の方向についても弱く支持される。
   「こ」が紛らわしいという部分は、1 音のデータでは支持されない。

## 6. 限界

- **1 音の曲線であって、読み札の通し読みではない。** 競技では「ほこる…」「こころ…」のように数拍を聞いた上で
  判断するので、2 拍目以降の情報や、読み手の速さ・抑揚の影響をこのデータは含まない。
  5 節 4 項の経路(2 拍目の「こ」による取り違え)は、この資料では確かめられない。
- **話者 1 名の合成音声である。** 競技の読み手は人間であり、読み手ごとの発音の違いがある。
  合成音声の「ほ」の立ち上がりの弱さが、人間の読み手にそのまま当てはまるとは限らない。
- **少数試行の音の不確かさが大きい。** 「ほ」は 66 試行、「こ」は 57 試行で、区分ごとには 5〜31 試行しかない。
  たとえば短い打ち切りの ほ→こ 10.7% の信頼区間は 3.7〜27.2% で、打ち切りなしでは 8 試行しかないため、
  割合の推定はほとんど意味を持たない。対称性の検定も、件数の少なさから有意にならない。
- **68 択の回答画面の影響。** 回答は画面上の 68 音から選ぶため、画面上の並びや選びやすさが回答に偏りを
  生みうる(「ほ」の回答が極端に少ないことはその疑いを含む)。
- **打ち切り点が音によって違う。** 「ほ」と「こ」で打ち切り点の組が違うため、「短い打ち切り」の中身も
  音によって同じではない。
