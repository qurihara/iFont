# 上毛かるた読み上げ音声の速度計測(timeFont / iFont 補助資料)

作成日: 2026-09-24

上毛かるた競技県大会規則(公益社団法人群馬県子ども会育成連合会)は、各札を 2 回読む(1 回目が本読み、2 回目が空読み)、空読みの終わりから次の本読みの第一音までは約 1.5 秒、本読みから空読みまでは約 5〜6 秒、と定めている。この文書上の値に対して、公開されている読み上げ音声が実際にどのくらいの速さ・間隔で読まれているかを計測した。

## 法的配慮(守った制約)

- 動画・音声は一切ファイルとして保存していない。yt-dlp・ffmpeg・MediaRecorder などは使っていない。
- ブラウザで動画を通常再生しながら、ページ内の Web Audio API(`createMediaElementSource` → `AnalyserNode` / `ScriptProcessorNode`)で、約 11.6 ms(512 サンプル / 44.1 kHz)ごとに次の派生特徴量だけを取り出した。音声サンプルは蓄えていない。
  - RMS(包絡)、ゼロ交差率、スペクトル重心(Hz)、1〜4 kHz と 0〜1 kHz のエネルギー比(dB)
  - 周波数帯域は 2 帯域のみで、音声を復元できる情報は含まない。
- 読み札の文言は群馬県の著作物なので、この文書と成果物には札の先頭かなとモーラ数だけを書く。

YouTube で「上毛かるた 県大会」「上毛かるた 読み手」「上毛かるた 読み上げ」を検索したが、実際の大会の読み手の声を通しで収めた動画は見つからなかった(ニュース映像 2 本のみ)。

## 方法

解析スクリプトは `/Users/kurihara/Library/CloudStorage/GoogleDrive-qurihara@gmail.com/マイドライブ/share/google_desktop_share/iFont/project/jomo_reading_speed/analyze.py`(python3.11 + numpy)。

1. RMS を dB にし、2 フレーム(約 24 ms)の移動平均で平滑化する。無音の床(10 パーセンタイル)と山(99 パーセンタイル)からしきい値(床 +12 dB か山 −32 dB の大きい方)を決め、しきい値を超える区間を、0.7〜0.9 秒未満の切れ目は繋いで「1 回の読み(区間)」とする。
2. 区間の中で、前後 0.25 秒の最大より 8 dB 以上落ち込む谷を「音節の切れ目」とみなす(区間末尾 0.35 秒の減衰は除く)。
3. 上毛かるたの節回しでは語尾の母音を長く引き伸ばす(2〜3 秒)ので、「本体」= 区間の始まりから最後の音節の立ち上がりまで、を別に出す。
   - 全体の速度 = モーラ数 ÷ 区間の長さ。本体の速度 = (モーラ数 − 1) ÷ 本体の長さ。
4. 第一音の長さ = 区間の始まりから最初の谷まで(0.45 秒以内に谷があるとき)。無ければ「判別できず」。包絡の谷で切るので、母音が続く場合(例: 「あさま」の「あ」→「さ」の s は無声なので谷が出るが、「おおた」の「お」→「お」は谷が出ない)は過大・判別不能になりうる。
5. 上の句/下の句の境目 = 上の句のモーラ比率から予想した時刻に最も近い谷(予想の ±25% 以内)。近似である。
6. 本読み/空読みの割り当て。規則どおりなら間隔が(5〜6 秒, 1.5 秒)と交互になるはずだが、どの素材もそうなっていなかったので、動画の説明欄の構成(「つ」から始まり各札 2 回)に従って先頭から 2 つずつ対にした。冒頭の「つ」2 区間は、同じ札が後で通常の対としても現れる(同一クリップ)ため二重計上を避けて集計から外した。
7. 札の特定。ランダム読み上げの動画は、画面の字幕が読まれている札と同期していない飾りのティッカーで、自動字幕も取得できなかったため、札を特定できなかった。そのため 44 札の平均モーラ数(上の句 7.6、下の句 6.4、計 14.0)で速度を出した。全 44 札が 1 回ずつ現れる素材では総モーラ数は 616 で確定なので、平均速度は正しく、札ごとのばらつきだけが過大に出る。marudai_all44 は説明欄の章立て(あ行から順)により、区切りがきれいな か・さ・ま・や行の 18 札を特定して実モーラ数で計算した。

## 規則の値との比較と読み取れること

1. **発話速度**。競技の節回し(announcer、gungun)では、1 札 14 モーラを約 6 秒かけて読み、全体では 2.3〜2.4 モーラ/秒である。ただしそのうち 2.2〜2.8 秒(発話時間の 38〜45%)は語尾の母音の引き伸ばしで、それを除いた本体は 3.5〜4.0 モーラ/秒である。普通の読み方(marudai)は 4.8〜4.9 モーラ/秒で、本体の速度に近いが語尾の伸ばしが無い。
2. **第一音**。包絡の谷で切れる範囲では、第一音は中央値 0.17〜0.25 秒(素材によらずほぼ同じ)。「ひ」「ふ」の札(読みは「びゃくえ」「ぶんぶく」で濁音から始まる)は、札を特定できた素材が無かったため個別には測れていない。
3. **間隔**。どの素材も規則の「本読みから空読みまで約 5〜6 秒」を再現していない。アナウンサー版は本読み→空読み、空読み→本読みとも約 4.1 秒で一定。ぐんぐん版は本読み→空読みが 1.24 秒、空読み→本読みが 1.3〜1.5 秒で、後者は規則の 1.5 秒に近いが前者は規則の 1/4 以下である。したがって「公式ルール準拠」は札の読み順・回数についての準拠であって、間隔まで規則どおりではない。実際の大会の間隔を測るには大会の音声が要る(見つからなかった)。
4. **本読みと空読みの音量差**。アナウンサー版は 43 対のうち 34 対が同一クリップの繰り返し(長さと音量が完全に一致)で、本読み・空読みの差は構造上ゼロである。ぐんぐん版は本読みと空読みが別テイクだが、平均音量の差は +0.4 dB で、実質差が無い。上の句と下の句の差も、アナウンサー版で −1.7 dB(下の句がやや大きい)、ぐんぐん版で +2〜3 dB(上の句がやや大きい)と小さく、「本読みは上の句を大きく、空読みは下の句を大きく」という規則の強弱は、どちらの素材でも音声上は確かめられなかった(下の句は語尾の引き伸ばしを含むので、減衰の影響もある)。
5. **素材ごとの差**。アナウンサー版とぐんぐん版で 1 札の発話時間(6.1 秒と 5.9 秒)、全体速度(2.3 と 2.4 モーラ/秒)はほぼ同じで、語尾の伸ばしはアナウンサー版の方が長い(2.8 秒と 2.2 秒)。本体の速度はアナウンサー版の方が速い(4.0 と 3.6 モーラ/秒)。ぐんぐん版の ① と ⑤ は同じクリップ集なので、素材としては 1 つと数えるべきである。

timeFont/iFont の観点では、競技で札が確定するまでの時間の目安として、本読みの第一音が約 0.2 秒、上の句(平均 7.6 モーラ)が約 2.0〜2.2 秒、本体全体で約 3.4〜3.7 秒、語尾を含めた 1 札で約 6 秒、という数字が得られた。

## できなかったことと理由

- 実際の県大会の読み手の音声は、YouTube で通しの動画が見つからず(ニュース映像は語りと混在)、測れていない。
- 指示にあった「ランダム読み上げ⑤」(IzU6lNxTzhQ)は非公開で、修正版で代替した。
- ウェブアプリ「上毛かるた」はストア案内ページで、ブラウザ上で音が鳴らないため解析不能。iOS/Android アプリは対象外。
- ランダム読み上げの動画で札を特定できなかった(字幕は非同期のティッカー、自動字幕は取得不能)。そのため速度は平均モーラ数による近似で、札ごとのばらつきは実際より大きく出ている。「ひ」「ふ」の第一音も個別には測れていない。
- 上の句/下の句の分割はモーラ比率と包絡の谷による近似で、句の境目が谷として出ない札では誤る。marudai_all44 の上の句・下の句の値は信頼できないので載せていない。
- 第一音の長さは包絡の谷でしか切れないため、母音が連続する札や鼻音で始まる札では判別できないか過大になる。
- アナウンサー版の本読み・空読みは同一クリップの繰り返しなので、両者の差(音量・速度)はこの素材からは測れない。

## 計測条件(論文の方法の節に書く数値)

- 再生環境: Claude Code の Browser pane(Chromium系)で YouTube のページを通常再生。動画・音声ファイルの取得や録音は行っていない。
- 特徴量の算出: ページ内で `AudioContext`(44.1 kHz)を生成し、`createMediaElementSource(video)` を `ScriptProcessorNode`(バッファ512サンプル)に接続。512サンプル(約11.6 ms)ごとに、RMS、ゼロ交差率、スペクトル重心(Hz)、1〜4 kHz と 0〜1 kHz のエネルギー比(dB)を計算し、`video.currentTime` とともに記録した。音声サンプル自体は保持していない。
- 発話区間の検出: RMS を dB に変換し、2フレーム(約24 ms)の移動平均で平滑化。しきい値は「無音の床(10パーセンタイル)+12 dB」と「山(99パーセンタイル)−32 dB」の大きい方。しきい値を超える区間を、0.7〜0.9秒未満の切れ目は連結して1回の読みとした。
- 音節の切れ目: 前後0.25秒の最大値から8 dB以上落ち込む谷。区間末尾0.35秒の減衰は除外。
- 本体と語尾の分離: 区間の始まりから最後の音節の立ち上がりまでを本体、それ以降を語尾の引き伸ばしとした。
- 第一音の長さ: 区間の始まりから最初の谷まで(0.45秒以内に谷がある場合のみ)。
- 上の句と下の句の境目: 上の句のモーラ比率から予想した時刻の±25%以内で最も近い谷。
- 本読みと空読みの割り当て: 動画の説明欄の構成(「つ」から始まり各札2回)に従い、先頭から2区間ずつ対にした。冒頭の「つ」2区間は集計から除外。
- 札の特定: ランダム読み上げの動画は札を特定できなかったため平均モーラ数で速度を算出。marudai_all44 は説明欄の章立てから18札を特定し実モーラ数で算出。
- 使用ソフトウェア: python3.11、numpy。スクリプトは analyze.py(再現手順は上の「ファイル」の節)。
